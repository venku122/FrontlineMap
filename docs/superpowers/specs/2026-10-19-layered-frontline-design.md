## Model
- Preserve Legacy mode for exact 1.5.3 numerical/replay compatibility; make GroundControl the new plugin default. Layer selection is explicit config plus on-screen buttons: GroundControl, AirThreat, NavalInfluence, Confidence, Legacy. Compute only selected field, not four full-resolution grids concurrently.
- ObservationStamp and NativeObservation gain public-observable role metadata (Unknown, GroundVehicle, Aircraft, Ship, Building, Airbase, AirDefense). Existing constructors default Unknown for compatibility. No hidden health/ammo/loadout/live-position inputs. Classify admitted native marker types only. Public unit definition names may identify SAM/SPAAG roles; unknown types stay conservative and labeled heuristic.
- Ground: ground vehicles weight3/radius6000m; airbases weight10/radius8000m; building configured weight4 multiplied0.15/radius2000m. Aircraft/ships contribute zero. AirThreat: aircraft weight0.5/radius20000m and publicly identifiable air-defense weight3/radius12000m; no ordinary buildings/airbases. NavalInfluence: ships weight5/radius16000m; no aircraft or buildings. Unknown stamps retain legacy semantics only in Legacy; Unknown is excluded from layered modes.
- Configurable per-role radii and stale half-life120s, contested balance ratio0.2, minimum front confidence0.5. Validate all settings before replacement; invalid reload retains previous output/settings. Defaults are explicit heuristic starting points, not certified weapon ranges.
- Confidence multiplier for stale positions = 0.5^(max(0, snapshot simulation time - observed time)/half-life); fresh=1. Preserve native known positions, never extrapolate hidden motion or infer deletion. Scale support by confidence. Accumulate confidence-weighted and raw support to calculate local weighted confidence. One unsupported side never produces gold. Contested band uses |F-E|/(F+E)<=0.2 above both support thresholds. Low-confidence contested area remains visible but subdued; precise gold requires local confidence>=0.5. Confidence view colors coverage confidence, not combat strength. Native removal/context changes still revoke immediately; no temporal filter retains revoked input.

## Terrain
- TerrainCostGrid is an immutable coarse static grid. Public static-map physics only; ignore all dynamic unit/ship layers. Classify land/water by sampled sea-relative height; unknown samples blocked. Eight-neighbor Dijkstra uses horizontal path distance, rejects ground slopes>35degrees and diagonal corner cutting (naval surface paths ignore seabed slope). Ground follows land, naval follows water. Air influence remains radial; do not pretend this implements radar LOS or actual weapon envelopes.
- TerrainSampler incrementally samples 128x128 cells, <=128 statics raycasts/frame and ~2ms time slice, cached per map extent and scene; no per-frame full-grid raycast. GlobalPosition conversion handles floating origin. Expose ready/known/land/water counters. Unknown cells remain unsupported. If unavailable, label it rather than silently claim terrain-aware output; explicit TerrainEnabled=false permits radial model.
- Path cost field per source is calculated on coarse terrain and sampled conservatively into the selected full-resolution field, with a direct source-to-cell offset. Cache scratch per job, bound scheduler chunks. No new terrain sampling during repaint.

## Contours/presentation
- FrontContours extracts UV segments with marching squares from cell-center F-E. Endpoint support eligibility and confidence checked; unsupported edges, one-sided fields and flat zero plateaus yield no line. Deterministic saddle handling. UV uses (column+0.5)/Columns and (row+0.5)/Rows, no mirroring.
- Draw vector segments as non-raycasting masked Unity UI geometry, screen-pixel width stable under zoom. Contours belong to staged publication and clear/rollback with texture; no orphan images or retained segments after revocation. Legacy retains current raster line exactly. Layered raster provides fill/contested band; vector gold line is separate. Air/naval views explicitly describe influence, not land ownership. Native icons stay above overlay.
- Legend: current layer, age, stale count, terrain availability/coarseness, heuristic label, confidence and color key. Compact clickable layer buttons, do not intercept native markers outside buttons. F9/F10 keep meanings.
